# 所有地图保持普通人物大小

2026-09-17。对照基线：`052b0aba1df7f276861fda8a774efa7d9043275d`。

普通地图分支原先仍使用 `max(1, renderHeight / innerMapHeight)` 填满高度。
艰苦洞穴和未知废矿区不满足旧矮图分类条件，因此仍会额外放大人物。
11-1 高度又大于其他编号地图，仅扩大分类阈值不能可靠解决问题。

现在所有地图的世界倍率固定为 1，与相同输出条件下的射手村一致。
人物、装备、宠物、怪物、NPC 和可交互地形共用该世界比例。
可见宽高取渲染尺寸与地图有效尺寸的较小值，多余空间居中留边。
外层窗口仍等比例缩放整帧；这里的 1 倍指内部渲染坐标，不是屏幕物理像素。

原有短宽地图的静态素材范围展开、地板相机约束、装饰背景拼接和
Buff/底栏独立裁剪继续保留。分类仅影响静态素材展开，不再决定人物倍率。
本次没有修改地图资源、碰撞坐标、背景装饰倍率或无边框全屏逻辑。
小房间和航行地图同样取消高度填充，可能出现新的上下留边，这是预期行为。
